# japanese-writing-gemini

[https://github.com/MetamoL/japanese-writing-gemini](https://github.com/MetamoL/japanese-writing-gemini)

`japanese-writing-gemini` は、人間が読むまとまった日本語文章の作成をGeminiに委任するための汎用AIエージェント向けスキルです。

公開README、技術ドキュメント、解説記事、ブログ、プロダクト紹介文などの作成において、エージェントがプロジェクト内の事実確認と要件整理（ブリーフ作成）を担当し、自然な日本語による文章全体の書き下ろしをGeminiに委任する役割分担を実現します。

※本スキル自体はGemini APIやMCPサーバーへの直接通信機能を含みません。生成されたブリーフの送信、ファイルへの反映、公開等の作業は利用者が手動で行います。

---

## 設計思想と役割分担

コードベースの解析や事実確認に強みを持つエージェントと、長文の自然な日本語生成に適したGeminiの特徴を踏まえ、作業領域を明確に分離しています。

- **エージェントの役割**:
  - 対象文書がGeminiへの委任に適しているかの判定と提案
  - リポジトリ内のソースコード、設定ファイル、既存資料に基づく事実確認
  - 秘密情報を除外した、Geminiにそのまま渡せる「コピー用ブリーフ」の作成
- **Geminiの役割**:
  - ブリーフに含まれる確認済みの事実に基づき、見出し構成、表、コードブロック、コマンド例などを含めた文章全体のゼロベースでの書き下ろし
- **利用者の役割**:
  - エージェントからの委任提案の明示的な承認
  - 作成されたブリーフのコピー＆Geminiへの送信
  - 生成文の確認（事実関係、コマンド、パス、安全性などの最小限の修正）および配置

## 対象ドキュメントと対象外

文書の用途と読者層に応じて、本スキルの適用対象を厳格に限定しています。

### 対象となる文書（Geminiに委任）

人間が通読することを主眼とした、まとまった日本語文章が対象です。

- 公開README
- 技術解説ドキュメント
- 記事・ブログエントリ
- プロダクトやツールの紹介文

### 対象外の文書（エージェントが直接記述）

以下は本スキルの対象外です。エージェント自身が正確性と圧縮性を優先し、直接執筆します。

- AI・エージェント向けの内部指示、プロンプト、スキル本文、引き継ぎ文
- オーナー向けのレビュー、作業報告、判断材料の提示
- 短いUI文言、ソースコード内のコメント、コミットメッセージ
- 単純な誤字脱字の修正

## ワークフロー

1. **対象文書の判定と承認**
   エージェントが作成予定の文書を分析し、Geminiでの執筆に適しているかを提案します。利用者が明示的に承認するまで次の処理へは進みません。
2. **事実確認とブリーフ作成**
   承認後、エージェントがプロジェクトのコードやドキュメントを精査し、確認済みの事実のみをまとめた1つのコピー用ブリーフを作成します。この際、利用者の秘密情報（認証情報やプライベートデータ）はブリーフに含まれません。
3. **Geminiによる新規書き下ろし**
   利用者がブリーフをGeminiに渡します。Geminiはブリーフ内の情報をもとに、既存の下書きに縛られることなく構成や表現を最初から組み立てて文章を生成します。
4. **事実確認と最小限の修正**
   利用者がGeminiの生成結果を確認します。本スキルはGeminiの文章を全面的に書き直すものではなく、事実、コマンド、パス、安全性、ライセンス条件などに問題がないかを点検し、必要な箇所のみ最小限の修正にとどめます。

## ファイル構成

- **`SKILL.md`**: スキルの定義および指示が記述された正本ファイルです。
- **`agents/openai.yaml`**: Codex環境向けの任意メタデータファイルです（スキルの基本動作には必須ではありません）。

## インストールと利用方法

本スキルは汎用Markdownとして定義されています。自動呼び出しの可否やトリガー方法は利用するエージェントの仕様に依存します。

### Codexでの利用

リポジトリの内容を以下のディレクトリに配置します。

```text
.agents/skills/japanese-writing-gemini/
```

明示的に呼び出す場合は、以下のように入力します。

```text
$japanese-writing-gemini
```

※`agents/openai.yaml`を配置することで、Codex向けメタデータとして認識されます。

### Claude Codeでの利用

正本である`SKILL.md`を以下のパスに配置します。

```text
.claude/skills/japanese-writing-gemini/SKILL.md
```

明示的に呼び出す場合は、スラッシュコマンドを使用します。

```text
/japanese-writing-gemini
```

### その他のエージェントでの利用

お使いのエージェントの指示セットやコンテキストに`SKILL.md`を直接読み込ませることで利用可能です。呼び出しや適用のルールは、各環境のプロンプト仕様に従ってください。
